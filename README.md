# Kali Dotfiles
My Kali Linux setup for OSCP prep, Proving Grounds, and OverTheWire.

## Includes
- **zsh** – Oh My Zsh + Powerlevel10k, autosuggestions, syntax highlighting, VPN switcher (`vpn htb|thm|pg`)
- **tmux** – `Ctrl+a` prefix, intuitive splits, tun0 IP in status bar, session logging

## Install
```bash
git clone git@github.com:offensivesecguru/dotfiles.git ~/dotfiles
cd ~/dotfiles && ./install.sh
```
